# Mentora-SN — Refonte du site

Cette branche contient la première version du nouveau site vitrine Mentora-SN dans `site-v2/`.

## Fonctionnement

- Site responsive en HTML, CSS et JavaScript statiques.
- Boutons d'inscription et de contact ouvrant WhatsApp avec la demande préremplie.
- Aucun compte ni données personnelles ne sont conservés par cette version.
- Les espaces privés (Parent, Élève, Professeur, École) sont présentés comme fonctionnalités à développer.

## Déploiement

Publier le contenu du dossier `site-v2/` comme racine d'un site statique. Le déploiement de démonstration est disponible sur le projet Vercel `mentora-sn-nouveau` de l'équipe `lumina-service`.

## Important

Le domaine historique `mentora-sn.site` et sa messagerie ne sont pas modifiés. Pour les connecter au nouveau site, récupérer d'abord leur gestion et sauvegarder les anciens contenus et messages.
